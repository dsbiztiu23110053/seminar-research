2.2 データの準備

データ読み込みと型変換・クリーニング 
# Windows環境の絶対パスを指定
data_path <- "C:\\Users\\js201\\OneDrive\\ドキュメント\\2026春\\ゼミ2\\データセット\\mobile_game_inapp_purchases.csv"

# データの読み込み
game_data <- read.csv(data_path, stringsAsFactors = FALSE)

# 実際の列名に合わせて数値型へ変換と欠損値（NA）の除去
game_data$Age <- as.integer(game_data$Age)
game_data$SessionCount <- as.integer(game_data$SessionCount)
game_data$InAppPurchaseAmount <- as.numeric(game_data$InAppPurchaseAmount)

# 必須変数のNAを完全に除去
game_data <- game_data[!is.na(game_data$SessionCount) & 
                       !is.na(game_data$InAppPurchaseAmount) & 
                       !is.na(game_data$Age), ]

# 文字列型の変数を因子（factor）型に変換
game_data$Country <- as.factor(game_data$Country)
game_data$Device <- as.factor(game_data$Device)
game_data$GameGenre <- as.factor(game_data$GameGenre)
game_data$SpendingSegment <- as.factor(game_data$SpendingSegment)

2.3 データセット概要

本研究では、Kaggleで公開されているモバイルゲームのユーザー行動およびアプリ内課金に関するデータセットを使用する。このデータには、ユーザーの人口統計学的属性、ゲームのプレイ傾向、および課金行動が記録されている。

データセットの概要
項目 内容
サンプル数 3,024件（欠損値処理前）
データの性質 クロスセクションデータ（ユーザー単位）
主な分析対象 ユーザーの年齢、プレイ頻度、累計課金額、ゲームジャンル

2.5 基本統計量

ユーザーの行動傾向を俯瞰するため、主要な連続変数（年齢、週あたりセッション数、累計課金額、熱中度スコア）の基本統計量を算出する。

2.6 データの可視化：累計課金額の分布

図 2.1 は、ユーザー全体の累計課金額（TotalSpend）の分布を示したものである。多くのユーザーが低額課金帯に位置する一方で、一部のユーザーが非常に高い金額を課金しているロングテールな分布の特徴が確認できる。

図（課金総額の分布）は、ユーザー全体における累計アプリ内課金総額（InAppPurchaseAmount）の分布を示したヒストグラムである。
分布は極端に左側に偏っており、50ドル未満の低額課金帯に大部分のユーザーが集中している。
その一方で、グラフの右側には数百ドル以上に達する長い裾（ロングテール）が伸びており、一部の少数のユーザーが非常に高い金額を課金していることが確認できる。

2.7 プレイ頻度と熱中度スコアの関係

図 2.2 は、週あたりのプレイ回数（SessionsPerWeek）と熱中度スコア（EngagementScore）の関係を示した散布図である。プレイ頻度が高いユーザーほど、ゲームへの熱中度スコアも高くなる強い正の相関が視覚的に認められる。

図(プレイ回数と課金総額の関係)は、ユーザーのプレイ回数と累計課金総額の相関を示した散布図である。
全体的な傾向として、課金総額が500ドル以下の低額課金帯に大部分のユーザーが集中しており、モバイルゲーム特有のロングテールな収益構造が確認できる。
また、プレイ回数と課金総額の間に明確な線形相関は見られなかった。

2.8 ジャンル別・デバイス別の行動パターン

ジャンル別の平均課金額

図（ジャンル別の平均課金総額）は、ゲームジャンルごとのユーザー1人あたりにおける平均累計課金額を比較したものである。
ジャンル間で課金傾向に大きな格差が存在しており、ストラテジー（Strategy）、MOBA、RPG といった競争や育成要素の強いジャンルにおいて平均課金額が突出して高いことが示された。
一方で、パズル（Puzzle）やカジュアル（Casual）といったライト層向けのジャンルでは平均課金額が低く留まっている。

デバイス別のプレイ頻度

図（デバイス別の平均プレイ回数）は、ユーザーが使用しているデバイス（AndroidおよびiOS）ごとの週平均プレイ回数を比較したものである。 両プラットフォーム間において平均プレイ回数に顕著な差は認められず、ユーザーはデバイスの環境に関わらず同程度の頻度でゲームをプレイしていることが示された。
