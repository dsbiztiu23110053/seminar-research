3  分析手法

3.1 手法の選定

本研究では、モバイルゲームにおける擬似的な「サービス終了（サ終）リスク」の発生要因を統計的に解明するため、ロジスティック回帰分析（Logistic Regression）を採用する。

目的変数が「サ終リスク群（1）」または「健全群（0）」という二値（バイナリ）データであるため、通常の線形回帰モデルではなく、確率を0から1の範囲に収める一般化線形モデル（GLM）の一種であるロジスティック回帰が最適である。本手法を用いることで、各ユーザー属性がリスク発生に与える影響度を「オッズ比」として定量的に評価・解釈することが可能となる。

手法の選定根拠
手法 対象データ 主な目的 利点
ロジスティック回帰 二値変数（0/1） リスク発生確率の予測と要因特定 係数を「オッズ比」として容易に解釈できる

3.2 ロジスティック回帰分析の理論的背景

ロジスティック回帰モデルでは、あるユーザーがサ終リスク（\(y = 1\)）に該当する確率を \(p = P(y = 1 | \mathbf{x})\) としたとき、確率 \(p\) のロジット変換（対数オッズ）を説明変数 \(\mathbf{x} = (x_1, x_2, \ldots, x_k)\) の線形結合で表現する。

\[\ln\left(\frac{p}{1-p}\right) = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \cdots + \beta_k x_k\] {#eq-logistic-logit}

ここで \(\beta_0\) は切片、\(\beta_1, \ldots, \beta_k\) は各説明変数の回帰係数である。この式を確率 \(p\) について解くと、以下のシグモイド関数（ロジスティック関数）が得られる。

\[p = \frac{1}{1 + \exp(-(\beta_0 + \beta_1 x_1 + \beta_2 x_2 + \cdots + \beta_k x_k))}\] {#eq-logistic-prob}

オッズ比（Odds Ratio）の解釈

説明変数 \(x_j\) が1単位増加したときのサ終リスクのオッズ比は、回帰係数 \(\beta_j\) を用いて \(\exp(\beta_j)\) と表される。オッズ比が1より大きければリスクを高める要因（危険因子）、1より小さければリスクを抑える要因（保護因子）として直感的に解釈できる。

3.3 サービス終了リスク（目的変数）の定義

本研究では、外部のサービス終了データを用いず、データセット内のユーザー行動から擬似的にサ終リスクをモデリングする。ゲーム運営の破綻を招く2大要因「過疎化（アクティブ低下）」と「売上低迷」を再現するため、以下の複合条件を満たすユーザーを「サ終リスク群（risk_flag = 1）」と定義する。

  • 条件1（過疎化の予兆）: 週あたりプレイ回数（SessionCount）が全ユーザーの下位25%以下
  • 条件2（売上低迷の予兆）: アプリ内課金総額（InAppPurchaseAmount）が全ユーザーの下位25%以下

この双方に該当するユーザーを 1、それ以外の健全なユーザーを 0 とする二値変数をR内で動的に生成する。

3.4 説明変数の設計

ロジスティック回帰モデルに投入する説明変数は、データセットに含まれるユーザーの人口統計学的属性およびプレイ環境に関する以下の4変数である。

説明変数の設計
変数名 型 説明 モデル内での扱い
Age integer ユーザーの年齢 連続変数としてそのまま投入
Country factor ユーザーの居住国 カテゴリ変数（ダミー変数化）
Device factor 使用デバイス（iOS / Android） カテゴリ変数（ダミー変数化）

3.6 モデルの評価指標

構築したロジスティック回帰モデルの適合度および各変数の有意性を評価するため、以下の指標を使用する。

p値（有意確率）

各説明変数の回帰係数 \(\beta_j\) が「0である（無関係である）」という帰無仮説を検定する。本研究では有意水準を 5%（\(p < 0.05\)） と設定し、統計的に有意なリスク要因を特定する。

赤池情報量基準（AIC）

モデルの適合度の良さと複雑さ（変数推定量）のバランスを測定する指標であり、以下の式で定義される。\[\text{AIC} = -2\ln(L) + 2k\] {#eq-aic}

ここで \(L\) は最大尤度、\(k\) は自由パラメータ数（定数項を含む係数の数）である。AICの値が小さいモデルほど、過学習を抑えた優れたモデルであると評価される。
